# Projection Booth｜双机展映亮度校样

把两台投影各自打白测得的灰度场放到同一张幕面坐标中。按各机的驱动上限试放，查看叠光、相对亮度差和单点贡献。可以分别下载单机线性驱动图，也可把白场、画面和设置作为一份校样留档。

运行 `./start.sh` 后打开 [校样台](http://127.0.0.1:19908/)。`BOOTH_PORT` 可改本机端口，`./start.sh stop` 停服务并保留命名数据卷。也可在虚拟环境安装 `requirements.txt` 后运行 `python -B -m booth`，数据默认落在当前的 `runtime-data`。

1. 打开合成练习，或导入同尺寸、已经对齐的单帧 8 位灰度 PNG。两张图的像素必须来自同一幕面位置，零表示该机没有有效光场。
2. 调整 A、B 的手动驱动、允许的驱动上限和暖冷偏移。可在原坐标填写评估范围和统一亮度目标。右下坐标是排他边界，左上为原点。
3. 查看合光、亮度偏差、原白场和两张单机驱动图。点图或输入原坐标进行点测，查看各机的驱动和相对亮度贡献。
4. 单机驱动图为线性 8 位灰度，255 是 100% 驱动。保存校样可得到包含本次白场、合光、偏差、两张驱动图和参数报告的 ZIP。
5. 合光预览也可以送入照片准备工作区继续整理。

一般校样输入每张 20 MiB，边长 8 至 2400 像素且总像素不超过 250 万。亮度是相对刻度，满驱白场 255 对应 100；假设驱动与亮度线性。色偏是亮度加权的暖冷指标，预览颜色为示意。此处为离线试放，不执行设备控制、自动配准或相机响应校准。内置练习全部由程序合成。
